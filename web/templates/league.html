Upload a CSV export of draft-eligible players from OOTP. The Player ID column can be anywhere in the file — it's detected automatically.

How to export from OOTP:
  1. In OOTP, go to the Rookie Draft page and open the draft pool
  2. Set filters: SHOW: All Players and POSITION: All Players to include the full pool
  3. Click View → Customize to open the view settings panel
  4. Check the ID field to include Player ID in the view, then click OK
  5. Click Export to CSV (bottom of screen or right-click menu)
  6. Choose Save as Global so it's easy to find
  7. Find the file in your OOTP folder: import_export/csv/

The Player ID column can be anywhere in the file — it's detected automatically.
