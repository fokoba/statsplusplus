Connection

API Token (recommended)

The sanctioned StatsPlus API auth — a per-team token used instead of your browser session cookie. Used automatically once set, and more stable than a cookie.
Where do I find this?
  1. Open statsplus.net, log in, and make sure you're linked to your team in this league.
  2. Click Prefs (top-right, next to Logout) to open your User Settings page.
  3. In the API Token box, copy the Current Token value (36 characters).

A token is valid for one team in one league — set it separately for each league you manage here. Tokens expire 90 days after creation; if refreshes start failing with a token error, log in on StatsPlus to refresh it and paste the new one here.

Session Cookie (fallback)

Used only when no API token is set above.
Where do I find these?
  1. Open statsplus.net and log in.
  2. Press F12 to open DevTools.
  3. Go to Application (Chrome) or Storage (Firefox).
  4. Expand Cookies → click https://statsplus.net.
  5. Copy the Value for sessionid and csrftoken.

Session cookies expire periodically. If refreshes start failing, repeat these steps to get a fresh cookie.
